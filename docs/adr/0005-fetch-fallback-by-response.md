# 페처 대체 경로는 소스별이 아니라 응답 기준으로 한 곳에 둔다

OpenAI 뉴스 같은 일부 사이트는 Cloudflare 챌린지라 직접 GET이 403이다. 소스마다 「이 소스는 프록시로」 플래그를 두면 모델·관리 화면·어댑터가 모두 늘고, 사이트가 차단 정책을 바꿀 때마다 사람이 따라가야 한다. 그래서 `HttpFetcher` 한 곳에서 응답이 봇 차단으로 보일 때(403·429·503, 또는 `cf-mitigated: challenge`·`<title>Just a moment`)만 설정 `FETCH_FALLBACK_URL`의 리더 프록시(예: r.jina.ai)로 한 번 더 받는다. 설정이 비면 꺼져 있고, 막히지 않는 소스는 동작이 바뀌지 않는다.

감수하는 것: 외부 서비스에 의존하고(프록시가 죽으면 차단된 소스는 전과 같이 실패), 읽으려는 원문 URL이 그 서비스에 전달된다. 수집 대상은 공개 기사 주소뿐이고 본문은 저장하지 않으므로 받아들인다. 헤드리스 브라우저는 운영 부담이 커서 택하지 않았다.
