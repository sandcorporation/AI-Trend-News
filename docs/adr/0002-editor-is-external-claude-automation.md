# 편집은 서버 코드가 아니라 외부 Claude 자동화가 MCP로 수행한다

번역·요약·중복 제거·게시 판단을 서버가 LLM API를 직접 호출해 처리하지 않고, 하루 2회 예약 실행되는 Claude Code 클라우드 자동화(편집자)가 원격 MCP로 들어와 수집물을 읽고 기사를 쓰는 방식을 택했다. 편집 기준을 코드 배포 없이 자동화 프롬프트로 바꿀 수 있고, portfolio에서 만든 원격 MCP 패턴을 그대로 재사용하기 때문이다. 서버에는 LLM 호출 코드가 없다.

## Consequences

- 편집자가 돌지 않으면 새 기사가 생기지 않는다. 서버는 대체 처리를 하지 않고 기존 기사를 유지하며 Discord로 경보만 보낸다.
- 크롤러는 수집물만 쌓는다. 수집물은 사이트에 직접 노출되지 않는다.
- 편집 품질과 비용은 자동화 쪽에서 관리하며, 서버는 수집물·기사·게시 상태의 저장소와 MCP 도구만 책임진다.
